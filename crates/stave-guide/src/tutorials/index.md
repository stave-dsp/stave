# Tutorials

Three tutorials take one plugin from an empty crate to a tested,
exported VST3 and CLAP plugin with a face. Each step's code is complete
and runs as part of the documentation build, so what you read is what
compiles today.

1. [Your first plugin](crate::tutorials::first_plugin): parameters,
   processing, smoothing, export, and loading it in a host.
2. [A face and meters](crate::tutorials::face_and_meters): a typed tap
   for the output level, a face of parts on a theme, and tests that
   drive the face like a person.
3. [Prove it](crate::tutorials::prove_it): the plugin's own property
   tests, measured, and every generic check from one line.

New to Stave? Start with [Getting started](crate::getting_started),
which builds and loads the worked example, Stave Tilt.
