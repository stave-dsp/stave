stave 0.2.0

stave-face: a design system for lit, composable instrument faces, replacing the old UI layer.

- A face is a theme plus a tree of parts: knobs, toggles, footswitches, lamps, selectors, steppers, presets, pages, meters, traces, pads and screens.
- Hardware forms: pedals, rack units, amp heads and speaker cabinets.
- Live grab targets, pages, display binds, momentary switches and lamp colours.
- A live storybook that any tool can drive.
- scripts/release.sh versions, gates, commits, tags and pushes a release.
