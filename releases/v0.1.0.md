stave 0.1.0

The first public release: a from-scratch Rust audio plugin framework, MIT-licensed, at github.com/stave-dsp/stave.

- VST3 and CLAP from hand-written ABIs, with no C or C++ SDK.
- The DSP library, the parameter model, telemetry, the host and measurement tools, and a native macOS editor.
- The plugins and the website moved to their own repositories (stave-plugins, stave-dsp.github.io).
