stave 0.3.0

The overhaul: one author API, verified wrappers, Linux and Windows, and a five-minute CI. Breaking: plugins written against 0.2 need migrating (see the getting-started guide).

Author API
- The umbrella `stave` crate: one `Plugin` trait, `stave::export!` for VST3 and CLAP with stable class IDs, and a prelude that is all most plugins import.
- Params by `ParamId` with natural-typed `value()`, `Smoother` and `Steps`, `Normalized` at the controller boundary, and a lifecycle state in which only a prepared plugin is processed.
- Telemetry through `Plugin::new`, typed taps via `#[derive(Taps)]`.
- Faces: named parts, grouped themes, text measured during layout, clipping and radial gradients, and new parts (clipped display, gain-reduction meter, route row, bipolar trace and lamp).

Platforms
- Linux and Windows: build, test, validators, and native faces (Win32 and X11) in CLAP and VST3, with portable text from embedded IBM Plex.
- The CLAP GUI extension and a note port for instruments.

Safety and verification
- Every unsafe block states its invariant; a typed Objective-C core; panics never cross into the host.
- Kani proofs, a seeded simulated host, protocol models checked against real traces, loom on the shipping types, fuzzing and sanitizers. They found and fixed real bugs (a dropped gesture end, NaN normalization, null output channels and more).

Testing
- `PluginHarness`, `plugin_checks!` (validation, no allocation, sample rates 8 kHz to 768 kHz, reset, automation, state, determinism) and `FaceDriver` for clicks, drags and overlays at named parts or exact coordinates, plus golden images.

Fixes
- f64 biquads at 768 kHz; value text round-trips; CLAP state rescan.
