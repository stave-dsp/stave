stave 0.4.0

Breaking: `NoParams` is now `Copy` and a public struct gained a field.

- Docs: a documentation site built from the code at stave-dsp.github.io/stave, replacing docs/. Its articles are doctests and its reference pages are generated.
- Fix: CLAP honours a breakpoint's pause like VST3 (one shared mute).
- Fix: `NoParams` has `Default`, so a plugin with no params compiles.
- Fix: `PluginHarness::prepare` resets as the wrappers do.
- Faster checks: validation mounts as one test per check, and the per-parameter checks run in four parts.
- CI: every framework change also builds and lints the plugins; a CLAP event fuzz target.
