stave 0.5.0

Breaking: units are types in stave-dsp (DSP.md U4/U5). Every setter and constructor that took a frequency, level or time as a bare `f32` takes `Hz`, `Db` or `Seconds`; `FilterSpec` holds them. The newtypes are `#[repr(transparent)]`, so the typed code compiles to the same instructions. The prelude now carries the units (`Hz`, `Db`, `Gain`, `Seconds`, `Ratio`, `hz`, `khz`, `db`, `ms`, `seconds`).

Migrating a plugin (one line per pattern, before → after)
- `FilterSpec::Peak { hz: 1_000.0, db: 6.0, q }` → `FilterSpec::Peak { frequency: hz(1_000.0), gain: db(6.0), q }` (every variant: `hz` is `frequency: Hz`, `db` is `gain: Db`)
- `x.set_hz(f)` → `x.set_frequency(hz(f))` (`Lfo`, `Osc`, `Wavetable`, `OnePole`, `DcBlocker`, `Allpass1`, `LinkwitzRiley4`, `Coupler`); `Crossover3::set_hz(lo, hi)` → `set_corners(hz(lo), hz(hi))`
- `OnePole::lowpass(800.0)`, `Svf::new(1_000.0, q)`, `Lfo::new(0.5)` → `OnePole::lowpass(hz(800.0))`, `Svf::new(hz(1_000.0), q)`, `Lfo::new(hz(0.5))`; `svf.set(f, q)` → `svf.set(hz(f), q)`; `one_pole.hz()` → `one_pole.frequency()` (a `Hz`)
- `c.set_attack_ms(10.0)` / `set_release_ms` / `set_lookahead_ms` / `set_time_ms` → `c.set_attack(ms(10.0))` / `set_release` / `set_lookahead` / `set_time`
- `Peak::new(1.0, 50.0)`, `Rms::new(10.0)`, `Lag::new(5.0, 50.0)`, `RandomWalk::new(140.0, 30.0, seed)` → the same with `ms(..)` per time
- `c.set_makeup_db(3.0)`, `l.set_ceiling_db(-1.0)`, `Limiter::new(peaks, -1.0)` → `c.set_makeup(db(3.0))`, `l.set_ceiling(db(-1.0))`, `Limiter::new(peaks, db(-1.0))`; `c.reduction_db()` → `c.reduction().get()`
- `GainComputer::gain_db(l)` / `output_db(l)` / `feedback_gain_db(o)` → `gain(db(l))` / `output(db(l))` / `feedback_gain(db(o))` (each a `Db`)
- `Sidechain::new(Some(80.0), None)` → `Sidechain::new(Some(hz(80.0)), None)`
- `Dattorro::new(100.0)`, `set_t60_s(2.0)`, `set_predelay_ms(20.0)`, `set_damping_hz(8_000.0)`, `set_bandwidth_hz(16_000.0)` → `Dattorro::new(ms(100.0))`, `set_t60(seconds(2.0))`, `set_predelay(ms(20.0))`, `set_damping(hz(8_000.0))`, `set_bandwidth(hz(16_000.0))`
- `Schroeder::set_t60_s(t)` → `set_t60(seconds(t))`; `Fdn::set_t60_s(t)` and `VelvetNoise::set_t60_s(t)` → `set_decay(seconds(t))` (their `set_t60(T60)` profile setters are unchanged); `Fdn::set_modulation_ms(d)` → `set_modulation(ms(d))`
- `DelayLine`-backed stages: `Delay::new(20.0, 10.0)` / `set_ms(ms)` → `Delay::new(ms(20.0), ms(10.0))` / `set_delay(ms(ms))`; `Comb::new(max, delay, fb)` / `DelayAllpass::new` / `set_delay_ms` → `ms(..)` for both times / `set_delay`
- `EnvelopeFollower::set_attack_ms` / `set_release_ms` / `set_slow_release_ms(Some(t))` → `set_attack(ms(..))` / `set_release(ms(..))` / `set_slow_release(Some(ms(t)))` (`EnvelopeTimes` keeps its `*_ms` fields)
- `PushPull::set_drive_db(d)` / `set_feedback_db(d)` → `set_drive(db(d))` / `set_feedback(db(d))`; `small_signal_gain_db()` / `ceiling_db()` / `gain_reduction_db()` → `small_signal_gain()` / `ceiling()` / `gain_reduction()` (each a `Db`)
- `SmoothSat::set_hf_smoothing(6.0)` → `set_hf_smoothing(db(6.0))`; `mod_lfo_hz(f, sync, bpm)` → `mod_lfo_rate(hz(f), sync, bpm)` (a `Hz`); `rise(age, 10.0, sr)` → `rise(age, ms(10.0), sr)`; `note_on(f, v)` / `key_position(f)` → `hz(f)`
- `tau_coeff(0.010, sr)` → `tau_coeff(ms(10.0), sr)`; `Tail::from_time_constant(t, sr)` → `Tail::from_time_constant(seconds(t), sr)`
- Converters and circuits: `Machine::with_rate(32_000.0)` → `with_rate(SampleRate::new(32_000.0))`; `Chip::delay_s(clock)` → `delay(clock)` (a `Seconds`); `clock_for(t)` → `clock_for(seconds(t))`; `Variable::with_ramp(0.01)` → `with_ramp(ms(10.0))`; `Tracking::draw(1.0, 40.0, seed)` → `Tracking::draw(db(1.0), db(40.0), seed)`
- A param into a setter: `filter.set_frequency(hz(p.cutoff.value()))` → `filter.set_frequency(p.cutoff.value_as())`, and per frame `ramp.next()` → `ramp.next_as::<Hz>()` (`Unit::Hz` yields `Hz`, `Unit::Db` yields `Db` or `Gain`, `Unit::Ms` yields `Seconds`, `Unit::Ratio` yields `Ratio`; debug builds check the unit)
- A name ending `_hz`, `_db`, `_ms` or `_s` in stave-dsp's public API now fails `scripts/check-vocabulary.sh` (the justified exceptions, f64 analysis queries among them, are listed in it with their reasons).
